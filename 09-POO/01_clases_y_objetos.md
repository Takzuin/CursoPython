# Clases y Objetos 🏠

En la Programación Orientada a Objetos (POO), todo gira en torno a **clases** y **objetos**.

## ¿Qué es una Clase?

Una **clase** es como un plano o una plantilla. Define la estructura y el comportamiento que tendrán los objetos creados a partir de ella.

Por ejemplo, si piensas en un "Coche", la clase definiría que todos los coches tienen color, marca y modelo, y que pueden arrancar y frenar. Pero la clase en sí no es un coche real, es solo la definición.

```python
class Coche:
    pass
```

## ¿Qué es un Objeto?

Un **objeto** es una instancia de una clase. Es la "cosa" real creada usando el plano.

Siguiendo el ejemplo anterior, un objeto sería "mi Toyota rojo" y otro objeto sería "tu Ford azul". Ambos son coches (instancias de la clase Coche), pero son entidades distintas.

```python
mi_coche = Coche()
tu_coche = Coche()
```

---

## Analogía

- **Clase**: El molde para hacer galletas.
- **Objeto**: Cada una de las galletas que salen del molde.
